# Support

Thanks for using **Apiboost OmniSpec**! This page explains where to get help.

## Community support (open-source core)

The open-source core is supported by the community and the Apiboost team on a
best-effort basis through GitHub:

- **Questions and how-to help:** search existing issues first; if you don't find
  an answer, open a new issue in the GitHub issue queue.
- **Bug reports and feature requests:** open an issue. See
  [`CONTRIBUTING.md`](./CONTRIBUTING.md) for what makes a good report.
- **Documentation:** see the [`README.md`](./README.md) and the guides under
  `docs/`.

Community support is provided without warranty or guaranteed response time, under
the terms of the [Apache License 2.0](./LICENSE.md).

Please **do not** use the public issue queue to report security vulnerabilities —
follow [`SECURITY.md`](./SECURITY.md) instead.

## What to include when asking for help

- The package version and product (open-source core or Pro).
- Your environment (Node.js version, browser, framework).
- A minimal reproduction and the exact error message or unexpected behavior.
