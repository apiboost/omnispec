# gRPC & Protobuf

OmniSpec Pro renders gRPC APIs directly from your `.proto` files. It documents
services and their RPCs, message types with nested fields, `oneof`s, maps and
enums, and clearly labels each method's streaming pattern (unary, server, client,
or bidirectional) — all with the same sidebar navigation, search, and theming as
the OpenAPI and AsyncAPI renderers.

:::info[Pro]
gRPC / Protobuf rendering requires
**[Apiboost OmniSpec Pro](https://apiboost.com/omnispec?utm_source=omnispec&utm_medium=docs&utm_campaign=pro)**, which is launching
soon. The free core renders OpenAPI 2.0 / 3.0 / 3.1 and AsyncAPI 2.x / 3.x;
GraphQL, SOAP/WSDL, and gRPC renderers are part of Pro.
:::
