# GraphQL

OmniSpec Pro renders GraphQL APIs from either an SDL schema or an introspection
result. It documents the full type system — object, interface, union, enum,
input, and scalar types — alongside the root `Query`, `Mutation`, and
`Subscription` fields, with argument and field descriptions, custom-scalar
`@specifiedBy` URLs, directives, and deprecations, all cross-linked with the same
sidebar navigation, search, and theming as the OpenAPI and AsyncAPI renderers.

:::info[Pro]
GraphQL rendering requires
**[Apiboost OmniSpec Pro](https://apiboost.com/omnispec?utm_source=omnispec&utm_medium=docs&utm_campaign=pro)**, which is launching
soon. The free core renders OpenAPI 2.0 / 3.0 / 3.1 and AsyncAPI 2.x / 3.x;
GraphQL, SOAP/WSDL, and gRPC renderers are part of Pro.
:::
